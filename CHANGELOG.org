#+TITLE: Changelog

* Unreleased

- Detect =TLE=: programs running past ~competitive-companion-time-limit~
  are killed. New options ~competitive-companion-time-limit~,
  ~competitive-companion-minimum-time-limit~ and
  ~competitive-companion-slow-test-delay~.
- Report test cases that are still running in the echo area.
- ~C-g~ aborts the running test case and skips the remaining ones, still
  showing the results so far.
- Show each failed test case's running time, and the slowest one when all
  tests pass.
- Run test cases in numeric order (=input10= no longer runs before
  =input2=).
- Accepted and timed out test cases run once, even when stderr is merged
  into the output.
- Add an ERT test suite, run by =guix build -f guix.scm=.
- Kill a program on time even when it never reads a large input (Emacs
  used to hang until ~C-g~).
- When a failed test case runs again to show stderr mixed with stdout and
  that run ends differently (nondeterministic programs), show the output
  of the judged run instead.

* 0.0.2

- Persist test cases in a hidden directory instead of temp files.
- Fix custom variable typing.
- Better filename generation options.
- Add option =competitive-companion-file-generation-hook=.
- Documentation fixes.

* 0.0.1

Initial release.

- Automatically download all task's sample test cases from Competitive
  Companion via a local server.
- Generate task's implementation file from a user-provided template.
- Run the program against all test cases and inspect wrong answers, with
  stdout/stderr diffing, in a =magit-section= based pop-up buffer.
- Add/remove/edit test cases easily.
- Detect basic verdicts (AC, WA, RTE).
- Progress reporting while running tests.
- Modeline support.
- Native =evil-mode= support.
- Configurable filename generation.
- Guix packaging.
- Info manual.
